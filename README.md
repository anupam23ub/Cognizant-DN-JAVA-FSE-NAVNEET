## 📌 About

This repository contains my **Cognizant Digital Nurture – Java Full Stack Engineer (FSE)** Deep Skilling work. It documents the hands-on exercises, case studies, framework implementations, frontend work, DevOps practices, and supporting concepts completed across the weekly curriculum.

The repository progresses from **DSA and design patterns** to **Spring, JPA/Hibernate, REST APIs, microservices, React, Git/CI-CD, Docker, Agile, and Gen-AI fundamentals**.

## 🗓️ Week-wise Learning Map

### Week 1 — Algorithms, Design Patterns & PL/SQL

The first week establishes the programming and software-engineering foundation.

- **Algorithms & Data Structures:** practical implementations using arrays, searching, sorting, collections and business-oriented problem statements.
- **Design Patterns:** hands-on implementations covering common creational, structural and behavioral patterns, along with concepts such as Singleton, Factory, Dependency Injection and MVC.
- **PL/SQL Programming:** database-side programming and procedural SQL exercises.

### Week 2 — Spring Core, Spring Boot & ORM

The second week moves into Java backend development and persistence.

- Spring Core and Dependency Injection
- Spring Boot application development
- Library Management implementations
- Employee Management System
- ORM and Hibernate/JPA concepts

### Week 3 — REST APIs & JWT Security

The third week focuses on developing backend services.

- Spring REST APIs
- HTTP methods and request/response handling
- REST hands-on exercises
- JWT-based authentication/security
- Building service-oriented backend applications

### Week 4 — Spring Boot, API Gateway & Code Quality

This week introduces backend architecture and supporting infrastructure.

- Spring Boot applications
- API Gateway
- Load-balancing concepts
- Sample microservice-oriented components
- SonarQube/code-quality practices

### Week 5 — React Fundamentals

Frontend development is introduced through React hands-on work.

- React fundamentals
- Component-based UI development
- Frontend application structure
- Practical React exercises

### Week 6 — Advanced React, Git & CI/CD

This stage expands frontend skills while introducing development workflow and automation concepts.

- Advanced React hands-on exercises
- Git and version-control practices
- Branching and collaboration concepts
- CI/CD fundamentals

### Week 7 — Agile, Docker, DevOps & Gen-AI

The final stage covers modern engineering practices beyond application coding.

- Agile Methodology
- Containerization using Docker
- DevOps and CI/CD
- Generative AI fundamentals
- Modern software delivery practices
